# Happy Food System 🍔🍕

## 📖 Overview
Happy Food System is a comprehensive and user-friendly Restaurant Management Web Application. It is designed to streamline the ordering process for customers while providing restaurant administrators with a robust dashboard to manage menus, orders, and daily operations efficiently.

## ✨ Features

### 🛒 For Customers:
* User Authentication: Secure login and registration for personalized experiences (`login.html`).
* Interactive Menu: Browse our delicious meals, categories, and prices (`menu.html`).
* Smart Cart System: Easily add, remove, and review items before purchase (`cart.html`).
* Seamless Checkout: Smooth, fast, and secure order placement (`checkout.html`).

### 👨‍🍳 For Administrators:
* Admin Dashboard: A centralized control panel to monitor the restaurant's performance (`admin.html`).
* Menu Management: Add, update, or remove food items dynamically.
* Order Tracking: View and fulfill customer orders in real-time.

## 🛠️ Tech Stack
* Backend: Python (Flask)
* Frontend: HTML5, CSS3, JavaScript
* Templating: Jinja2 (Server-side rendering)
